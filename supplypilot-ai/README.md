# SupplyPilot AI

Демонстрационный MVP для кейса HackAlem 2026: автоматизация формирования заказов поставщикам для ТОО «Электрокомплект».

## Что показывает прототип

- дашборд рекомендаций по ИЭК и SystemElectric;
- прогноз спроса с сезонным коэффициентом и устойчивым трендом;
- учёт текущего остатка и товара в пути;
- округление заказа по MOQ/кратности;
- риск дефицита и краткое обоснование по каждой позиции;
- AI-помощник, который объясняет расчёт простым языком;
- фильтры по поставщику и срочности;
- ручное подтверждение заказа без автоматической отправки поставщику.

## Методология для презентации

1. Берём месячную историю продаж за 24 месяца.
2. Очищаем выбросы: продажи выше верхнего порога IQR помечаются как разовые крупные заказы и не увеличивают регулярный прогноз.
3. Если товар был в stockout, оцениваем упущенный спрос по соседним месяцам и добавляем его к обучающей выборке.
4. Строим базовый прогноз по медиане/взвешенному среднему, затем применяем сезонный коэффициент текущего месяца и тренд роста.
5. Потребность на горизонт поставки сравнивается с остатком и количеством в пути.
6. Положительная потребность округляется вверх до MOQ/кратности поставщика.
7. AI-слой формирует объяснение на основе тех же рассчитанных признаков. Он не принимает решение об отправке заказа самостоятельно.

## Запуск

Откройте `index.html` в браузере. Для презентации достаточно локального открытия файла.

## Следующий этап для production

Заменить демо-массив в `index.html` на API загрузки Excel/1С, вынести расчёт в backend, добавить авторизацию, аудит ручных корректировок и подключить LLM через серверный ключ с обезличенными признаками.

## Добавленный функционал профиля и поддержки

В `index.html` добавлены:

- регистрация и вход через формы в модальных окнах;
- локальная демо-сессия `supplypilot_session` и список пользователей `supplypilot_users`;
- профиль: редактирование имени/email и смена пароля;
- пункты «Мой профиль» и «AI-поддержка» в боковом меню;
- чат с локальными ответами для демо-сценариев;
- функция `askLLM(messages)` для вызова серверного маршрута `/api/support/chat`.

Важно: `localStorage` и пароль в демо предназначены только для показа интерфейса. В production добавьте таблицу `users` (id, login, email, password_hash, name, avatar_url, created_at), таблицу `support_messages` и backend-роуты `/api/auth/register`, `/api/auth/login`, `/api/auth/me`, `/api/auth/password`, `/api/support/chat`. Пароли храните только через Argon2/bcrypt, сессии — в httpOnly secure cookie. API-ключ OpenAI/Claude храните только на сервере.
